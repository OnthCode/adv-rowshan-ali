# Advocate Rowshan Ali — Website (Demo)

Personal website for Advocate Rowshan Ali, Supreme Court of Bangladesh, Head of The Lawyers' Chamber.

Static site — no build step. Open `index.html` or deploy the folder as-is (e.g. Vercel, Netlify, GitHub Pages).

- `index.html` — page
- `styles.css`, `chat.css` — design
- `app.js`, `chat.js` — interactivity (law explorer, Q&A, quiz, WhatsApp-style chat)
- `data.js` — editable content (laws, Q&A, quiz, quotes, contact details)
